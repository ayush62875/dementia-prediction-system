# 🧠 Dementia Prediction System

A Machine Learning-based web application that predicts the likelihood of dementia from patient-related clinical and lifestyle features using a trained **Random Forest Classifier**.

The application also provides **Explainable AI (XAI)** using **SHAP (SHapley Additive exPlanations)** to help understand how individual features influence the model's prediction.

> ⚠️ **Disclaimer:** This project is developed for educational and research purposes only. The prediction generated by this application is **not a medical diagnosis** and should not be used for clinical decision-making.

---

## 📌 Project Overview

Dementia is a group of conditions associated with a decline in memory, thinking, and the ability to perform everyday activities.

This project demonstrates how Machine Learning can be applied to dementia-related data to build a predictive system.

The application allows a user to enter patient information and generates:

* Dementia prediction
* Dementia probability
* Prediction confidence
* Risk assessment
* SHAP-based model explanations

### 2. Dementia Prediction

The trained **Random Forest Classifier** generates a binary prediction:

* `0` → No dementia predicted
* `1` → Dementia predicted

The application also displays the model's predicted probability.

---

### 3. Risk Assessment

Based on the model-generated dementia probability, the application categorizes the result into:

| Probability  | Risk Level       |
| ------------ | ---------------- |
| `< 30%`      | 🟢 Low Risk      |
| `30% – <70%` | 🟡 Moderate Risk |
| `≥ 70%`      | 🔴 High Risk     |

These thresholds are application-level categories and **do not represent clinical diagnostic thresholds**.

---

### 4. Explainable AI with SHAP

The project uses **SHAP** to explain the predictions made by the Random Forest model.

The application provides visual explanations such as:

* SHAP Waterfall Explanation
* SHAP Beeswarm/Feature Impact Explanation
* Feature Importance Explanation

SHAP helps identify which input features contributed to an individual prediction and in which direction they influenced the model output.

## 🤖 Machine Learning Model

### Random Forest Classifier

The final application uses a **Random Forest Classifier**.

Random Forest is an ensemble learning algorithm that combines multiple decision trees to make a more robust prediction.

### Why Random Forest?

* Handles nonlinear relationships.
* Works well with mixed feature types after preprocessing.
* Less prone to overfitting than a single decision tree.
* Provides feature importance information.
* Works well for classification problems.

The trained model is stored in:

```text
models/random_forest_model.pkl
```

A scaler used during preprocessing is stored in:

```text
models/scaler.pkl
```

## 🔬 Explainable AI

The project uses **SHAP (SHapley Additive exPlanations)**.

Instead of only showing:

```text
Prediction = Dementia
```

SHAP helps answer:

```text
Why did the model make this prediction?
```

For an individual patient, SHAP values show the contribution of different features to the model output.

### Basic interpretation

```text
Positive SHAP contribution
        ↓
Pushes model output toward the target prediction

Negative SHAP contribution
        ↓
Pushes model output away from the target prediction
```

SHAP explanations should be interpreted as explanations of the **machine learning model**, not as medical causation.

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/ayush62875/dementia-prediction-system.git
```

Move into the project directory:

```bash
cd dementia-prediction-system
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate the virtual environment on Windows:

```powershell
venv\Scripts\activate
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Application Locally

From the project root directory:

```bash
streamlit run app/app.py
```

The application will open in your browser.

---

## ☁️ Deployment

The application is deployed using **Streamlit Community Cloud** and connected to the GitHub repository.

The deployment automatically uses:

```text

```

as the main application file.

The trained model is loaded dynamically using the project directory structure so that the application can work both locally and in deployment environments.
